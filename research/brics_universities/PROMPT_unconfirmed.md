# Промпт для локальной сессии (браузер): неподтверждённые вузы

Скопируйте всё ниже в локальную сессию и приложите файл `BRICS_неподтверждённые_для_заполнения.xlsx`
(репозиторий, ветка `claude/brics-universities-research-rt2drz`, папка `research/brics_universities/output/`).

---

## Задача

База из ~1 470 университетов стран БРИКС+ готовится для рассылки приглашения в проект «Университетская спутниковая
группировка БРИКС» (кубсаты, сверхнизкие орбиты). По **244 вузам** данные не подтверждены: облачная сессия не смогла
открыть официальный сайт или достоверность низкая. У тебя есть обычный браузер — открой сайты и заполни пробелы.

## Файл

`BRICS_неподтверждённые_для_заполнения.xlsx`, лист «Неподтверждённые». Колонки A–I — справка, **не меняй**
(A — технический ключ, не удаляй). Жёлтые колонки J–W — для заполнения:

| Колонка | Что вписать |
|---|---|
| J. Ректор | Действующий ректор / президент / vice-chancellor. Китай: `Pinyin (汉字)`; Россия/Беларусь/Казахстан/Узбекистан: `Фамилия Имя Отчество`; остальные: `Prof. Имя Фамилия` |
| K. Почтовый адрес | Полный, с индексом, как на официальном сайте |
| L. E-mail общий / ректората | Один адрес |
| M. E-mail международного отдела | Один адрес международного отдела / управления международного сотрудничества |
| N. Телефон | С кодом страны |
| O. ФИО адресата | Руководитель международного отдела (начальник, директор, проректор по междунар. деятельности) |
| P. Должность адресата | Как на сайте |
| Q. Обращение | Китай: `Dear Director Wang,`; Индия/ЮАР/Нигерия/Египет/Иран/ОАЭ/Саудовская Аравия: `Dear Prof. Фамилия,` / `Dear Dr. Фамилия,`; Бразилия: `Dear Prof. Фамилия,` (последняя фамилия); Россия/Беларусь/Казахстан/Узбекистан: `Уважаемый(ая) Имя Отчество!`; ЮВА: `Dear Prof. Фамилия,`. Нет имени — пусто |
| R. QS 2027 | Место или диапазон (напр. `412`, `801–850`); если вуза нет в рейтинге — `не в рейтинге` |
| S. THE 2027 | Так же |
| T. Webometrics | Место в мировом рейтинге (январь 2026 или новее) |
| U. Нац. рейтинг | Название и место, напр. `NIRF 2025: 57`, `RUF 2025: 134`; нет — пусто |
| V. Источник (URL) | Точная страница, где увидел данные (контакты — официальный сайт вуза) |
| W. Комментарий | Вуз закрыт / объединён / переименован / сменил домен; что не нашлось; CAPTCHA |

## Правила

1. Только то, что видишь на официальных страницах (сайт вуза и поддомены, министерство, космическое агентство,
   официальные страницы вуза). Ничего не выдумывай и не подбирай адреса по шаблону домена. Нет данных — пусто,
   а в W напиши, чего не нашёл.
2. Рейтинги бери со страниц самих рейтингов (QS, THE, Webometrics, национальные). Если вуз явно отсутствует —
   пиши `не в рейтинге`, не оставляй пусто.
3. Источник (V) — для каждой заполненной строки. Строки с источником получат высокую достоверность.
4. **Не обходи защиту:** CAPTCHA, вход, блокировка по стране — не обходи (без VPN и прокси); запиши в W
   «CAPTCHA / блокировка» и иди дальше.
5. Ничего не отправляй: письма, формы, регистрации — нельзя.
6. E-mail копируй дословно. В L/M не вписывай адреса приёмной комиссии и вебмастера; если есть только они — напиши в W.
7. Закрыт/объединён/переименован — название не меняй, опиши в W и впиши данные нового сайта.
8. Несколько кампусов — бери головной вуз.

## Порядок

1. Иди сверху вниз (отсортировано по стране). Если сайт не открылся — `www`/без, `http`/`https`, английская и местная
   версия, поддомены (`international.`, `oia.`, `global.`), разделы Contact / Administration / International Office.
2. Для скорости скачай один раз таблицы рейтингов (QS, THE, Webometrics, национальный) и сопоставляй по сайту/названию;
   неоднозначные совпадения помечай в W.
3. Сохраняй как `BRICS_неподтверждённые_заполнено.xlsx` после каждых 10 вузов. Порядок строк и колонки A–I не меняй.

## Что вернуть

1. Файл `BRICS_неподтверждённые_заполнено.xlsx`.
2. Короткий итог: сколько обработано; сколько не удалось открыть; закрытые/объединённые/переименованные вузы; где CAPTCHA.
